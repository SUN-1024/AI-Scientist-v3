# 医学图像分割中的患者级机器遗忘

状态：已准备 AI-Scientist v3 任务；执行状态见同目录 execution.json。本文是研究任务定义，不是实验结果。

## 研究问题
当患者要求移除其训练数据的影响时，能否以低于完整重训练的代价，使分割模型接近“从未使用这些患者训练”的参考模型，同时保留其他患者的器官分割能力，尤其是边界和小结构？

拟定工作题目：Anatomy-Preserving Patient-Level Unlearning for Medical Image Segmentation（医学图像分割中的解剖结构保持型患者级遗忘）。题目是工作方向，尚无成功方法或创新性结论。

## 为什么不能只做应用迁移
已有 To forget is to preserve: Machine Unlearning for 3D medical image segmentation（https://arxiv.org/abs/2606.16180）讨论该应用。因此不能写“首次将机器遗忘用于医学分割”。本任务检验的具体方向是：删除训练影响、保留解剖边界、计算代价三者之间是否有可复现的改善。

## 可证伪的判断
1. 若遗忘集变化伴随未见患者分割能力同样下降，优先解释为模型损坏。
2. 若同等时间的普通微调达到同样效果，不能声称结构约束是原因。
3. 若 Original/Retrain 尚未充分学习，不能从它们的接近推出遗忘成功。
4. 若只在输出上接近 Retrain，仍不能推出内部信息或成员信息已被删除。
5. 不以遗忘集 Dice 越低越好作为成功定义。
